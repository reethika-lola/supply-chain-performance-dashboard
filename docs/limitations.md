# Limitations

- The dataset is historical public portfolio data, not a verified live operating system.
- The downloaded CSV and supplied data dictionary are the final authority because public mirrors can differ.
- No supplier, warehouse, carrier, inventory, COGS, promised delivery date, or real-time event stream is provided.
- Late delivery risk is a source-provided flag and is not independently recalculated.
- Item-level facts require distinct order counts.
- This descriptive analysis cannot establish causality.
- Customer-shaped fields are intentionally excluded from the analytical model.
