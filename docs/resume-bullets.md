# Resume Bullets

1. Built a reproducible supply-chain analytics project in MySQL and Tableau, modeling public order-item data into a star schema for sales, profitability, delivery-risk, product, and regional analysis.
2. Developed data-quality checks, cleaning logic, Tableau-ready SQL views, and KPI definitions that prevent duplicate order counting at item-level fact grain.
3. Designed three Tableau dashboard specifications with documented calculations, filters, validation steps, and business-analysis guardrails for missing inventory and supplier data.
